Attacker text overrides system instructions ("ignore previous instructions", DAN-style jailbreaks, role overrides). Mitigation: clearly delimit untrusted input, treat skill content as untrusted, and refuse to disclose system prompts.

Instructions embedded in knowledge files (HTML comments, zero-width chars, chat-template separators) that the human reviewer can't see but the LLM executes. Strip non-printable Unicode and reject hidden directives.

Skill defines tools with dangerous primitives (shell, raw SQL, eval) or wildcard scopes. Use narrowly-scoped tools, parameterized queries, allowlists, and least-privilege credentials.

Skill grants the agent power to take irreversible or high-impact actions (payments, deletes, sends) without confirmation. Require human-in-the-loop for state-changing operations and rate-limit external calls.

API keys, tokens, or passwords inlined in skill content end up in logs, backups, and prompt history. Rotate immediately and reference secrets via environment variables or a vault.
